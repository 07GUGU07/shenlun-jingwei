# 申论经纬 · 五位一体备考图谱

一个可离线使用的国考 / 京考申论主题网页。以“五位一体”为骨架，加上党的建设、行政执法、京考首都特色三个专题，共 **8 个母主题、51 个子主题、102 个精炼案例、102 条金句、453 个规范词释义**。

## 打开方式

直接双击 `index.html` 即可。无需安装、无需联网，样式与数据都在本地。

手机阅读建议发布到 GitHub Pages，步骤见 **[DEPLOY.md](DEPLOY.md)**。

## 内容结构

每个子主题固定包含：

- **观点逻辑**：3 条，按“破题—论证—落笔”或“问题—原因—对策”组织，方便直接搭作文骨架。
- **常考规范词 + 释义**：10 个左右，每个词配一句大白话解释，点击词条可复制；手机上可一键“收起释义”只看词。
- **点睛金句**：2 条，标注领导人讲话、党的二十大报告、经典名句等出处。
- **精炼案例**：2 条，基本控制在 20—45 字，按“谁 + 做了什么 + 取得什么效果”组织，并标注来源。
- **交叉提示**：说明与哪些母主题交叉、考场上如何搭桥。
- **专有名词加粗**：如 **枫桥经验**、**接诉即办**、**两区建设**、**中轴线** 等，在正文中自动加粗。

## 标注规则

| 标注 | 含义 |
| --- | --- |
| 国考高频 | 国考近年反复出现的主题或设问 |
| 京考高频 | 京考材料、题目反复出现的方向 |
| 京考独有 | 北京特有的制度品牌、地名、政策；国考一般不会直接考，但可迁移 |
| 执法卷 | 国考行政执法卷专属素材；京考不单独分执法卷，可用于执法岗面试 |
| 交叉 | 可同时服务两个以上母主题，适合做作文“过渡段” |

> 重要：国考自 2022 年起分副省级综合管理、地市级综合管理、行政执法三类卷；京考公共科目申论不单独分执法卷，2027 年大纲仍为一张申论卷。

## 网页功能

- 8 张母主题卡片，点开进入子主题手风琴。
- 按“国考高频 / 京考高频 / 京考独有 / 行政执法卷 / 交叉”筛选。
- 全站搜索：标题、规范词及释义、金句、案例、提示均可搜。
- “随机抽背”：先看题目，再展开答案。
- 每个子主题可勾选“已掌握”，进度保存在本机浏览器。
- 支持全部展开 / 收起、规范词释义收起、打印当前页。
- 手机端：索引折叠、字号放大、筛选横滑、底部回到顶部；可添加到主屏幕。

- `app.js`：路由、筛选、搜索、抽背、进度等交互。

## 使用提醒

- 数据截至 **2026 年 11 月**；政策数据请以官方最新发布为准。
- 案例为公开报道的概括转述，考场上不必逐字复述，但人物、地点、做法、效果不要编造。
- “京考独有”是北京特色设问 / 素材，不代表国考完全不涉及同类主题。
- 网页只是“索引 + 素材库”，不能替代真题训练；建议配合近 5 年国考、京考真题使用。

## 发布成 GitHub Pages

完整步骤见 **[DEPLOY.md](DEPLOY.md)**。本地仓库已经初始化并提交，用 Git 命令只需三步：

1. GitHub 新建 **Public** 空仓库（不要勾选 README）。
2. 在项目目录执行：

```powershell
cd "C:\Users\Admin\Desktop\作品\D\D2"
$env:Path += ";C:\Program Files\Git\cmd"
git remote add origin https://github.com/<你的用户名>/shenlun-jingwei.git
git push -u origin main
```

3. 仓库 Settings → Pages → `main` / `/ (root)` → Save，等待 1—3 分钟，访问：

```text
https://<你的用户名>.github.io/shenlun-jingwei/
```

手机上用 Safari / Chrome 打开，再“添加到主屏幕”。
